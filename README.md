# bab-userscripts
Tampermonkey Userscripts for Bab AlBahrain.

## Usage
1. Install [Tampermonkey](https://www.tampermonkey.net/) for your browser
2. **Important:** Allow Tampermonkey to execute scripts by following [this guide](https://www.tampermonkey.net/faq.php?locale=en#Q209) for your browser
3. Install any userscript you'd like using the table below

## Scripts

|---|---|---|---|
